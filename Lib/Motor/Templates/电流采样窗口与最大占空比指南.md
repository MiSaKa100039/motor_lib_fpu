# 电流采样窗口与最大占空比确定指南

本文档用于确定相电流反馈可用的 ADC 采样时刻和 `cfg.limit.max_duty_cycle`。重点对象为低侧双分流采样，同时说明相线分流与霍尔采样的验证差异。

## 1. 先确认采样拓扑

| 拓扑 | 电流有效条件 | 最大占空比的主要限制 |
| --- | --- | --- |
| 低侧相电阻双采样 | 采样瞬间，被测相低侧器件处于稳定导通状态 | 低侧导通窗口、死区、模拟链路恢复和 ADC 时间 |
| 相线分流电阻 | 相电流持续流经传感器，仍需避开开关干扰 | 最小脉宽、死区、噪声及驱动约束 |
| 相线霍尔传感器 | 电流持续可见，通常不依赖低侧导通窗口 | 霍尔带宽、延迟、开关共模干扰及驱动约束 |
| 母线单电阻 | 仅在特定有效矢量窗口可重建相电流 | 需独立调制/多点采样算法，当前库不支持 |

ADC 到物理 `U/V/W` 的映射以及实际安装了哪些通道，由 BSP 定义。Platform 中的：

```cpp
cfg.sensor.invert_phase_current_u
cfg.sensor.invert_phase_current_v
cfg.sensor.invert_phase_current_w
```

仅用于修正已映射到物理相后的采样符号。

## 2. 低侧采样窗口模型

以下推导适用于中心对齐 PWM、低侧在载波顶点附近导通、ADC 在顶点附近采样的方式。

定义：

| 符号 | 含义 |
| --- | --- |
| `f_pwm` | PWM 频率 |
| `T_pwm = 1 / f_pwm` | PWM 周期 |
| `D` | 被测相最大占空比，范围 `0..1` |
| `T_low` | 顶点附近低侧器件总导通窗口 |
| `t_offset` | ADC 触发点相对导通窗口中心的偏移绝对值 |
| `t_dead` | 死区及换相不可用时间 |
| `t_settle` | MOS 开关噪声、运放/隔离放大器恢复和 RC 建立时间 |
| `t_adc` | ADC 采样保持所需时间；如必须等转换完成，再计入转换时间 |
| `t_margin` | 设计保留裕量 |

近似低侧导通窗口：

```text
T_low = (1 - D) * T_pwm
```

若 ADC 接近窗口中心，采样点距离最近开关边沿的可用时间为：

```text
T_edge = T_low / 2 - t_offset
       = (1 - D) * T_pwm / 2 - t_offset
```

应满足：

```text
T_edge >= t_required

t_required = t_dead + t_settle + t_adc + t_margin
```

因此最大占空比为：

```text
D_max <= 1 - 2 * (t_required + t_offset) / T_pwm
```

该公式用于产生初始安全值，最终值必须由示波器测量验证。

## 3. 当前工程参数示例

当前工程关键参数位于 `Core/Src/main.c` 与 `BSP/Motor/BSP_Motor.cpp`：

| 项目 | 当前值 |
| --- | ---: |
| TIM1 时钟 | `170 MHz` |
| PWM 模式 | 中心对齐 |
| `ARR` | `4250` |
| PWM 频率 | `170 MHz / (2 * 4250) = 20 kHz` |
| PWM 周期 `T_pwm` | `50 us` |
| ADC 触发 | TIM1 CH4 |
| `CCR4` | `ARR - 10` |
| 触发点相对顶点偏移 `t_offset` | `10 / 170 MHz = 0.059 us` |
| TIM1 死区参数 `DTG` | `128` |
| 定时器 `ClockDivision` | `DIV1` |
| ADC 时钟 | `170 MHz / 4 = 42.5 MHz` |
| ADC 注入采样时间 | `6.5 cycles` |

### 3.1 死区时间

STM32 高级定时器的 `DTG=128` 位于非线性编码区；在 `t_DTS = 1 / 170 MHz` 时：

```text
t_dead = (64 + 0) * 2 * t_DTS
       = 128 / 170 MHz
       ≈ 0.753 us
```

该值应以最终 CubeMX 配置和栅极实测波形复核。

### 3.2 ADC 时间

ADC 采样保持时间近似为：

```text
t_acquire = 6.5 / 42.5 MHz ≈ 0.153 us
```

如果 ADC 结果必须在当前窗口内全部转换完成，还应计入 12 bit 转换周期。对于判断采样点是否落在稳定模拟电压区，至少应计入 `t_acquire`，并通过实测补充模拟链路建立时间。

### 3.3 不同最大占空比的低侧窗口

| `D_max` | 顶点附近总低侧窗口 `T_low` | 半窗口减触发偏移 `T_edge` |
| ---: | ---: | ---: |
| `0.90` | `5.00 us` | `2.441 us` |
| `0.92` | `4.00 us` | `1.941 us` |
| `0.95` | `2.50 us` | `1.191 us` |

扣除当前估计的死区和 ADC 采样保持时间：

```text
t_base = t_dead + t_acquire
       ≈ 0.753 us + 0.153 us
       ≈ 0.906 us
```

剩余可用于开关噪声消退、放大器恢复和设计裕量的时间为：

| `D_max` | `T_edge - t_base` |
| ---: | ---: |
| `0.90` | 约 `1.535 us` |
| `0.92` | 约 `1.035 us` |
| `0.95` | 约 `0.285 us` |

由此可见，`0.95` 对当前低侧分流方案很紧，首次测试应从 `0.90` 或更低开始。本工程当前平台配置为：

```cpp
cfg.limit.max_duty_cycle = 0.90f;
```

## 4. 初始占空比计算表

在 `T_pwm = 50 us`、`t_offset = 0.059 us` 的条件下，可按测得的 `t_required` 选择上限：

| 总要求时间 `t_required` | 理论 `D_max` 上限 | 调试建议起始值 |
| ---: | ---: | ---: |
| `1.0 us` | `0.958` | `0.93` 至 `0.94` |
| `1.25 us` | `0.948` | `0.92` 至 `0.93` |
| `1.5 us` | `0.938` | `0.90` 至 `0.92` |
| `2.0 us` | `0.918` | `0.88` 至 `0.90` |
| `2.5 us` | `0.898` | `0.85` 至 `0.88` |

“调试建议起始值”故意低于理论上限，用于覆盖温升、母线变化、不同相位 duty 分布和探头未发现的瞬态问题。

## 5. 示波器测试准备

### 5.1 安全条件

1. 采用可限流电源，并将限流设置到板卡和电机允许的调试范围。
2. 将软件过流阈值临时降低到测试所需的安全范围。
3. 从低母线电压或很小电压矢量开始。
4. 保持随时可以执行停机或硬件急停。
5. 在验证采样窗口前，不进入大电流闭环运行。

### 5.2 推荐测量通道

| 示波器通道 | 测量内容 | 目的 |
| --- | --- | --- |
| CH1 | 被测相桥臂开关节点或低侧栅极信号 | 确定低侧稳定导通区 |
| CH2 | 相应采样放大器 ADC 输入前的模拟输出 | 观察尖峰与建立时间 |
| CH3 | ADC 触发定位信号，或临时翻转 GPIO 标记触发/ISR | 定位采样时刻 |
| CH4 | 电流钳或独立电流基准 | 对照真实电流 |

若无法直接输出 ADC 触发事件，应临时增加与触发时刻对应的调试 GPIO，或依据 TIM1 CH4 与计数器配置计算后再用波形验证。

## 6. 低侧采样最大占空比测试流程

### 步骤 1：确认静态零点

PWM 关闭时执行 ADC 零点校准，确认：

```text
i_a, i_b, i_c 接近 0
```

零点未稳定时不要继续提高占空比。

### 步骤 2：确认相映射与符号

使用 `DEBUG_PWM_MANUAL` 和很小 `delta`，分别给 U、V、W 相施加电压。对于定义为“逆变器输出流向电机”为正的方向，预期为：

| 发波相 | `Iu` | `Iv` | `Iw` |
| --- | ---: | ---: | ---: |
| U | 正 | 负 | 负 |
| V | 负 | 正 | 负 |
| W | 负 | 负 | 正 |

完成该步骤后再进行高 duty 窗口测试，否则符号/映射问题会混入采样窗口结论。

### 步骤 3：定位采样时刻

在低 duty 下观察：

1. 低侧开通边沿与关断边沿。
2. 采样模拟输出在开关边沿后的尖峰与恢复过程。
3. ADC 触发标记是否位于稳定窗口内。

记录：

```text
t_dead_measured
t_settle_measured
t_offset_measured
```

不要只依赖注释中的“顶点采样”；中心对齐 PWM 与触发边沿选择必须用波形确认实际事件位置。

### 步骤 4：计算第一版 `D_max`

选择安全裕量，例如：

```text
t_margin = 0.3 us 至 0.8 us
```

计算：

```text
t_required = t_dead_measured + t_settle_measured + t_adc + t_margin

D_max = 1 - 2 * (t_required + t_offset_measured) / T_pwm
```

将配置设置为小于计算结果的保守值：

```cpp
cfg.limit.max_duty_cycle = calculated_duty_with_margin;
```

### 步骤 5：逐级提高占空比验证

建议按以下方式逐级验证，不要直接跳到计算上限：

```text
0.80 -> 0.85 -> 0.88 -> 0.90 -> 0.92 -> ...
```

每一级观察：

- 采样模拟输出在 ADC 触发时刻是否已稳定。
- 软件电流是否出现突变、锯齿放大、偏置漂移或方向异常。
- 软件电流与外部电流基准是否一致。
- 电流环输出是否因错误反馈出现突然补偿。

出现任一下列现象时，上一档即应作为候选上限，并继续降低留裕量：

- ADC 触发点进入尖峰或恢复区。
- 软件电流随 duty 增大突然失真，而外部电流没有相同变化。
- 闭环出现无原因的 `Id/Iq` 跳变或发散趋势。

### 步骤 6：在不同电角度和工况复核

不能只在单一相或单一转子角度确定 duty 上限。至少检查：

- U/V/W 三个桥臂分别成为最高 duty 的情况。
- 正负转矩电流方向。
- 母线电压最低与最高运行值。
- 板卡冷态与热态。
- 电流达到计划工作范围附近的情况。

最终 `max_duty_cycle` 应取所有验证工况下均可靠的较小值。

## 7. 相线分流或霍尔采样测试流程

相线/Hall 采样无需为低侧导通窗口预留同样的 duty 空白，但仍应优化采样时刻：

1. 继续使用 PWM 同步采样，避免异步采样造成周期性纹波混叠。
2. 在中心对齐 PWM 的稳定区域采样，避免距离开关边沿太近。
3. 用示波器测量传感器输出在开关瞬态后的恢复时间。
4. 验证最高计划 duty 下 ADC 触发点仍处于低噪声区域。
5. 同时验证霍尔/隔离放大器带宽和相位延迟不会明显损害电流环。

对于此类采样，`max_duty_cycle` 通常主要受以下因素约束：

- 驱动器最小开通/关断脉宽；
- 自举供电刷新；
- 死区非线性；
- 过调制与电压矢量失真；
- 传感器输出的开关共模恢复时间。

不能仅因为相电流持续可测就直接允许 `100%` duty。

## 8. 代码配置位置

当前工程最大 duty 配置位于 `Platform/Motor/Platform_Motor.cpp`：

```cpp
cfg.limit.max_duty_cycle = 0.90f;
```

该限制在 `Motor_Manager.cpp` 输出 PWM 前生效，将每相 duty 限制在：

```text
0 <= duty <= max_duty_cycle
```

注意：当前为逐相截断 duty。进入限幅后可能改变期望电压矢量形状，因此最大 duty 应作为保护边界，不应作为正常运行长期饱和点使用。

## 10. 结论规则

- 低侧采样的 duty 上限由最差工况下的有效低侧采样窗口决定。
- 相线/Hall 采样仍需同步并避开开关瞬态，但通常不受低侧窗口直接限制。
- 理论计算只给出第一版上限；最终配置必须由实际模拟波形与外部电流基准验证。
- 对当前 `20 kHz`、顶点附近采样、`DTG=128` 的工程，`0.90` 是合理的初期验证起点；提高到 `0.92` 或更高前，应完成上述实测记录。
