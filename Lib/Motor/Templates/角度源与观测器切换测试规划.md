# 角度源与观测器切换测试规划

本文用于验证 `cfg.observer.startup_source`、`cfg.observer.steady_source`、
位置传感器故障处理以及未来观测器交接逻辑。台架运行必须限流、限制占空比，
并准备硬件急停；静态拒绝类测试应优先在不带功率输出的条件下完成。

## 1. 配置入口与当前边界

`Platform_MotorFeatures.h` 决定固件编译进哪些角度源能力；
`Platform_Motor.cpp` 中的 `cfg.observer` 只能从已编译且已实现的能力中选择运行链。
填写 `cfg.observer` 不会自动打开 `LIB_MOTOR_ENABLE_*`。

| 组合 | 设计目的 | 当前版本应允许启动吗 | 依据 |
| --- | --- | --- | --- |
| `SENSOR + SENSOR` | 编码器/霍尔直接作为 FOC 角度 | 是 | 已实现 `SENSOR_ONLY` 与故障停机 |
| `IF + SMO` | IF 建角加速，SMO 中高速接管 | 仅允许开发验证 | 切换框架存在，但 SMO 估计与收敛判据未完成 |
| `HFI + SMO` | HFI 零/低速，SMO 中高速 | 否 | HFI 注入与主动源交接未实现 |
| `SENSOR + SMO` | 传感器低速，SMO 中高速 | 否 | 主动源仲裁及无跳变回退未实现 |
| `HFI` 稳态反馈 | 高频注入持续闭环 | 否 | 配置占位存在，执行路径被拒绝 |
| `NONLINEAR_FLUX` / `LUENBERGER` / `EKF` | 高级稳态反馈 | 否 | 仅枚举占位 |

当前阻断项：

- `Observer_HFI.h` 和 HFI 参数是占位，尚无可执行注入及解调路径。
- `Observer_SMO.h` 当前实现没有使用传入的电压/电流反馈，不能视为真实 SMO 估计器。
- `runObserverLoop()` 中更新 `event.observer_converged` 的逻辑仍为 TODO，因此 `IF + SMO`
  不能完成可验收的自动接管。
- `HFI_ONLY`、`FUSION` 和 `SENSOR + SMO` 回退分支虽有状态机占位，但正常配置校验
  必须阻止当前固件进入这些路径。

### 当前冗余能力与预留接口

当前可执行的冗余检查只有 `position.enable_redundant_rotor_sensor` 配合
`position.health.enable_redundant_check`，即两个同轴物理传感器之间的角差检查；
它只能诊断并停机，不能接管主反馈角度。

为避免后续混淆，`observer` 中预留了影子观测器接口：

| 配置项 | 含义 | 当前行为 |
| --- | --- | --- |
| `enable_redundant_observer_check` | 并行运行无感观测器并检查其与主反馈角差 | 必须保持 `false`；置 `true` 后拒绝启动 |
| `redundant_observer_source` | 选择候选 `SMO/HFI/NONLINEAR_FLUX/LUENBERGER/EKF` | 仅占位，不自动编入算法 |
| `max_redundant_observer_error_rad` | 主反馈角与影子观测角允许差值 | 执行链实现后使用 |
| `redundant_observer_confirm_ticks` | 连续超差确认 tick 数 | 执行链实现后使用 |
| `sensor_fault_action` | 主传感器确认失效后的动作 | 当前只有 `STOP` 可执行 |

未来实现建议：观测器算法本体放在 `Lib/Motor/Observer`；影子源的有效性、
角差计数、接管仲裁应由该目录下新增的统一冗余/仲裁组件完成，并由
`MotorManager::runObserverLoop()` 调用；关断 PWM 与锁存 `Fault` 仍由
`MotorManager` / FSM 负责，避免算法模块自行决定功率输出。

## 2. 测试观测量与故障码

每次测试至少保存下列数据：

| 数据 | 判读用途 |
| --- | --- |
| `mon.state` / `mon.fault_code` | 是否被拒绝启动或是否进入故障锁存 |
| `mon.mode` / `mon.run_phase` | 是否错误进入 `ALIGNMENT`、`FORCE_DRAG`、`SMO_ONLY`、`HFI_ONLY` 等阶段 |
| `mon.event.observer_converged` | 候选观测器是否宣称可信 |
| `mon.angle_elec` / `mon.angle_elec_command` | 控制使用角与 IF/VF 命令角 |
| `mon.angle_elec_observer` / `mon.observer_error` | 候选观测角及其与传感器的差异 |
| `mon.sensor_ready` / `mon.sensor_health` | 主转子传感器有效性与原始故障原因 |
| `mon.rotor_redundancy_error` | 同轴双传感器的一致性误差 |
| `mon.i_d` / `mon.i_q` / `mon.duty_a..c` | 交接或失效瞬间是否发生冲击 |

当前已定义且与角度源相关的预期故障：

| 故障 | 应出现的条件 | 不应混淆为 |
| --- | --- | --- |
| `OBSERVER_UNAVAILABLE` | 所选算法未编入，或策略/执行链尚未实现 | `PARAM_ERROR` |
| `SENSOR_CONFIG_ERROR` | 选择传感器反馈但接口缺失，或辅助传感器配置不完整 | `SENSOR_LOSS` |
| `PARAM_ERROR` | 阈值、确认计数、减速比或基础配置非法 | `OBSERVER_UNAVAILABLE` |
| `SENSOR_LOSS` | 已配置的主反馈传感器在启动检查或运行中不再 ready | `SENSOR_SIGNAL_ERROR` |
| `SENSOR_SIGNAL_ERROR` | 主反馈传感器给出超时、CRC、磁场异常、定时器异常或角跳变 | `SENSOR_LOSS` |
| `SENSOR_MISMATCH` | 主/冗余转子传感器连续超出角差阈值 | 输出轴形变量 |
| `OBSERVER_LOSS` | SMO 已接管后失效且启动源为 IF，没有安全回退角度 | `SENSOR_LOSS` |
| `OBSERVER_MISMATCH` | 主反馈角与影子观测器角度连续超差 | 当前预留，执行链完成前不得产生 |

主传感器故障动作规则：

| 条件 | 当前行为 | 完成接管链后的预期行为 |
| --- | --- | --- |
| `sensor_fault_action=STOP` 且传感器失效 | 以 `SENSOR_LOSS` 或 `SENSOR_SIGNAL_ERROR` 停机 | 保持不变 |
| 请求接管，但影子观测器未连续收敛或角差不合格 | 当前配置阶段报 `OBSERVER_UNAVAILABLE` | 保留原传感器故障并停机，不盲切 |
| 请求接管，影子观测器已连续收敛且交接角差合格 | 当前配置阶段报 `OBSERVER_UNAVAILABLE` | 切换反馈源，记录事件；后续观测器失效报 `OBSERVER_LOSS` |

## 3. 执行顺序

1. 编译能力和静态配置拒绝测试：确认错误配置在 `pwm_enable()` 前被拦截。
2. `SENSOR + SENSOR` 正常启动及故障注入：确认已有可执行闭环链。
3. 辅助传感器与保护联动测试：确认监测源不会错误接管控制角。
4. `IF + SMO` 开发阻断测试：确认当前不得宣称完成自动切换。
5. 实现 HFI/SMO 有效性与交接后，再执行未来验收用例。

## 5. 默认启动模式与 API 安全门测试

| 编号 | 操作/条件 | 预期结果 |
| --- | --- | --- |
| M01 | `STOP` 状态调用当前 `start()` | 请求当前固定的 `VELOCITY_CONTROL`；速度环已接入但仍需目标初始化和台架整定验收 |

## 6. 有感闭环运行测试

| 编号 | 操作/注入 | 预期结果 |
| --- | --- | --- |
| S01 | 合法 `SENSOR + SENSOR`，主传感器 ready 且健康 | 启动进入 `SENSOR_ONLY`；`angle_elec` 跟随 `angle_elec_sensor` |
| S02 | 在 `DEBUG_VF_DRAG` 或 `DEBUG_IF_DRAG` 中只观察主传感器 | 角度和健康码可见；主传感器失效本身不因未被选作反馈而停机 |
| S03 | 闭环运行中令 `is_ready()` 连续失效达到 `invalid_confirm_ticks` | `SENSOR_LOSS`，立即关断 PWM 并进入 `ERROR` |
| S04 | 分别注入 `BUS_TIMEOUT`、`CRC_ERROR`、`MAGNET_ERROR`、`TIMER_NOT_RUNNING` | `SENSOR_SIGNAL_ERROR`，进入 `ERROR` |
| S05 | 启用角跳变检查并制造超过阈值的一拍机械角跳变 | 健康码为 `ANGLE_JUMP`，故障为 `SENSOR_SIGNAL_ERROR` |
| S06 | 故障清除前再次发启动命令 | 不得恢复驱动；必须显式 `clearFault()` 后重新启动 |

S02 应关闭冗余一致性保护，或单独记录其结果：冗余保护属于安全检查，即使主传感器
仅作监测，只要明确启用了该保护，超差仍会合法触发 `SENSOR_MISMATCH`。

## 7. 辅助传感器与安全故障联动测试

| 编号 | 操作/注入 | 预期结果 |
| --- | --- | --- |
| A01 | 同轴主/冗余角差始终小于阈值 | 不报 `SENSOR_MISMATCH` |
| A02 | 连续角差超限达到 `redundant_confirm_ticks` | `SENSOR_MISMATCH`，冗余健康码为 `REDUNDANT_MISMATCH` |
| A03 | 仅输出轴角度因减速器回差/弹性偏差增大 | 可记录 `transmission_deflection_rad`，不得误报同轴不一致 |
| A04 | 运行时注入过流、过压、欠压或过温 | 分别锁存 `OVERCURRENT`、`OVERVOLT`、`UNDERVOLT`、`OVERTEMP` 并停机 |
| A05 | 试图等待 `STALL` 或 `PHASE_LOSS` 自动保护 | 当前不得作为验收项；两项检测尚未实现 |

保护故障可与观测器故障同时出现在位掩码中。记录时应保留完整
`fault_code`，不能只记录最后看到的一种原因。

## 9. HFI 与多源切换未来验收

当前只执行 C17/C18，确认所有 HFI 或高级观测器闭环选择被拒绝。完成算法、
注入电压叠加、有效性判据和无跳变交接后，增加以下测试：

| 编号 | 策略/条件 | 验收结果 |
| --- | --- | --- |
| F01 | `HFI + SMO` 从零速升速 | HFI 建角有效，SMO 收敛后平滑接管 |
| F02 | `HFI + SMO` 从高速降至低速或 SMO 失效 | 平滑回 HFI，电流不冲击且注入开启时机正确 |
| F03 | HFI 信号幅值/频率超安全范围 | 配置阶段报 `PARAM_ERROR` 或明确的新故障，不允许带病注入 |
| F04 | `SENSOR + SMO` 升速切换 | SMO 接管前传感器持续可监测，交接角差合格才切换 |
| F05 | `SENSOR + SMO` 中 SMO 失效、传感器健康 | 安全回到 `SENSOR_ONLY` |
| F06 | `SENSOR + SMO` 中传感器失效、SMO 未可信 | 必须停机，不得盲切 |
| F07 | 两个候选源同时不可信 | 立即关断并报告明确角度源丢失故障 |
| F08 | 传感器作为主反馈，影子观测器连续角差超限 | 报 `OBSERVER_MISMATCH`，不得以错误候选接管 |
| F09 | 主传感器失效且动作选 `STOP` | 保留 `SENSOR_LOSS`/`SENSOR_SIGNAL_ERROR` 并立即关断 |
| F10 | 主传感器失效且动作选接管，影子源已在故障前可信 | 无角度跃变地接管；若条件不满足则按 F09 停机 |

完成标准：

- 当前允许的 `SENSOR + SENSOR` 链所有正常与故障用例通过。
- 所有未实现观测器或未实现切换组合都在驱动输出前被拒绝。
- 任一运行故障都可由监控量与故障码定位，且不会自动恢复输出。
- 新增任何观测器能力前，先实现有效性判据与故障映射，再启用对应 feature 宏，
  最后补齐并执行本规划中的未来验收项。
